# 验收清单

交付方按它自查，验收方按它检查。每一项都要能拿出证据（命令输出、测试名、截图、代码位置）。有一项不满足就退回，并写明原因和需要补的内容。

## 1. 交付物齐全

- [ ] **交付说明里有 `go test -race -count=1 ./...` 的完整结果（全部通过）和 `tools/e2e` 冒烟输出、新功能截图。缺任何一项直接退回，不看代码。**

- [ ] 分支名符合 `feat|fix|docs/<任务编号>-<简短英文>`，基于最新的 main。
- [ ] 交付说明包含：改了什么、为什么、取舍、验证命令与结果、截图、已知限制、更新过的文档。
- [ ] 只包含任务范围内的改动；`git diff main --stat` 里没有无关文件、生成物（`build/`、根目录的 `serval` 二进制）、临时文件。

## 2. 功能

- [ ] roadmap 里该任务的每一条“验收标准”都满足，并能指出对应的测试或截图。
- [ ] 正常路径、错误路径、取消路径都处理了：网络断开、密码错误、用户中途关闭面板。
- [ ] 错误提示面向用户：说明发生了什么、怎么处理，不出现 `handshake failed` 这类底层原文。
- [ ] 没有破坏已有功能：全量测试通过，冒烟流程通过。

## 3. 安全与数据

- [ ] 新数据存进保险库，没有写到别的文件或系统钥匙串（系统安全存储只用于“记住”保险库密钥）。
- [ ] 秘密保存前调用了 `requireProtection`；未加密的保险库里不会出现秘密（有测试检查 `vault.json` 不含明文）。
- [ ] 写记录用 `hostChange`、`keyChange` 或 `vault.JSONChange`；新增的记录类型、字段登记进了 [storage.md](storage.md)。
- [ ] 日志、提示、测试输出里没有密码、私钥、口令。
- [ ] 关闭面板时清空了输入的秘密。
- [ ] 主机密钥校验没有放松；新的网络监听只绑定回环地址（测试工具）或经用户明确开启（端口转发）。
- [ ] 新依赖（如有）是宽松协议，交付说明写了理由；没有复制 GPL、AGPL 或没有许可证的代码。

## 4. 代码

- [ ] `gofmt -l .` 没有输出，`go vet ./...` 通过。
- [ ] 分层正确：`core/` 没有 import MyGo 或应用层；界面代码没有直接拼装 SSH 配置之外的底层细节。
- [ ] 线程正确：`app` 字段只在主线程修改，后台结果通过 `a.post` 回来；`go test -race` 通过。
- [ ] 资源释放：连接、文件、goroutine 在取消和出错时都能退出（检查 `defer`、`context`）。
- [ ] 注释解释为什么，和代码一致；没有留下被注释掉的代码、调试输出、TODO 而不说明。
- [ ] 命名准确，没有顺手重构无关代码。

## 5. 测试

- [ ] `go test -race -count=1 ./...` 全部通过，交付说明里贴了结果摘要。
- [ ] core 逻辑有单元测试；新流程有界面测试；修复缺陷有先失败后通过的回归测试。
- [ ] 测试不依赖开发者本机环境（ssh-agent、`~/.ssh`、系统钥匙串、网络）。
- [ ] 没有为了让测试通过而放宽断言或加长等待；偶发失败查清了原因。

## 6. 界面与体验

- [ ] 真机截图覆盖新界面的浅色和深色。
- [ ] 颜色全部来自 `design.Of`；没有暖色系；强调色只有靛蓝，红色只用于生产环境和危险操作。
- [ ] 文案是简体中文，按钮写动作，同一界面可点击文字不重复。
- [ ] 可访问性：图标按钮有 `Label` 和 `Tooltip`；没有嵌套按钮；键盘可以完成主要操作。
- [ ] 动效：没有改变终端宽度的布局动画；系统开启“减少动效”时没有多余运动。
- [ ] 窄窗口（最小 760×420）下内容不溢出、不被裁掉。

## 7. 文档

- [ ] README 的功能说明、验证结果、已知问题已更新。
- [ ] 改了架构、线程模型、数据格式的，[architecture.md](architecture.md)、[storage.md](storage.md) 已更新。
- [ ] [roadmap.md](roadmap.md) 中该任务标为已完成，写了分支名；发现的范围外问题记进“待整理”。

## 验收方的额外检查

- 在干净的工作目录检出分支，自己跑一遍 `go test -race -count=1 ./...` 和 `tools/e2e` 冒烟流程，不只看交付方贴的结果。
- 抽查新增测试：临时改坏对应的实现，确认测试会失败（测试真的在测东西）。
- 涉及安全或数据格式的改动，逐行读 diff。
